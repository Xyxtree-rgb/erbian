# 耳辩 · 与尔同辩

> 在你耳边，与尔同辩。
> 一个**能杠、能玩、能复盘**的法律对抗演练场 —— 不替你说话，只逼你把话说赢。

**在线体验**：http://47.122.109.160　（手机端访问 `/mobile`）

---

## 一、它到底是什么

市面上的法律 AI 都在帮你**写完**：合同审查、文书生成、类案检索 —— 红海。
没有人帮你**辩赢**。

耳辩是一款语音辩论游戏：你说一句话，AI 对手当场怼回来，AI 裁判当场判定你这句
**成不成立、属于哪类论证、造成多少伤害、为什么**。血条会掉，判词会盖章。

游戏是壳，对抗演练是核，AI 裁判与真实案例库是护栏。

---

## 二、三个核心能力（缺一即退化）

| 能力 | 具体是什么 | 缺了会怎样 |
| --- | --- | --- |
| **可杠** | 你说一句它当场怼一句，血条掉一格 | 退化成问答机器人，练不出现场感 |
| **可玩** | 血条 / 渡口 / 果冻动效 / 多音色语音，你是来"再来一局"的 | 退化成课程或题库 |
| **可复盘** | 每轮回看：哪句有效、哪句只是情绪、哪句法条引错 | 退化成杀时间小游戏 |

关键在于**判定是可量化的**，不是关键词匹配。AI 裁判对每句话输出结构化结论：

```json
{ "valid": true, "type": "法条援引", "damage": 18, "reason": "援引《劳动合同法》第 39 条，但适用前提不成立" }
```

## 三、玩法

**断案（单集剧 · 纵深）**
一桩案子 → 调查取证 → 与对手辩论 → 判词盖章。目前 3 个章节。

**渡口（长线剧 · 横向）**
一条竖着的河，每站一个渡口、一个人、一场必须赢的仗。读法是摆渡人视角 ——
你送走一个个人，自己也一年年老去。

**知识库**
117 条真实案例，9 大分类（消费纠纷 / 劳动争议 / 食品安全 / 医疗美容 / 知识产权 /
网络治理 / 生态环保 / 动物保护 / 产品质量）。每条带**官方法条原文、发布机构、来源链接、
发布日期**，可逐条核验。辩论中可直接调取作为证据。

## 四、技术架构

```
浏览器（单文件 index.html · 无构建链）
   │  语音输入 / 语音合成 / 血条与判词渲染
   ▼
Flask 单服务（routes/api.py）
   ├── /api/judge         AI 裁判：判定这句话成不成立
   ├── /api/solo-turn     单人模式：AI 对手回怼
   ├── /api/tts           edge-tts 多音色语音
   └── /api/knowledge     117 条案例检索
   ▼
DeepSeek（deepseek-chat）+ 117 条真实案例库
```

- **前端**：纯 HTML/CSS/JS 单文件，无框架无打包，改完刷新即可
- **后端**：Flask + Flask-Cors，gzip 压缩（服务器只有 1.6G 内存，每一 KB 都要省）
- **AI**：DeepSeek 承担裁判与对手双重角色，四种辩风人格（青洏证据流 / 桃弁共情流 / 墨澜法条流 / 择安程序流）
- **语音**：Web Speech API 输入 + edge-tts 输出
- **联机**：房间码 + 轮询 + rev 版本号（服务器资源受限，不启用 WebSocket）

## 五、快速启动

```bash
pip install -r requirements.txt

# 在项目根目录创建 .env，填入密钥（.env 已被 .gitignore 排除）
echo "DEEPSEEK_API_KEY=sk-your-key-here" > .env

python app.py
# 打开 http://127.0.0.1:5001
```

服务器部署见 `DEPLOY.md`（systemd 配置、gzip、swap、资源限制都有记录）。

## 七、数据说明

知识库 117 条案例全部来自公开可查的官方通报与裁判文书，每条包含
`law`（法条原文）、`source`（发布机构）、`source_url`（原文链接）、`publish_date`。
**可逐条核验**，这是内容的护城河。

## 九、关于定位（避免误读）

耳辩 **不是** AI 法律助手，**不是** 法律咨询工具，**不是** 普法课件。
它不产出任何法律意见，所有判定仅服务于训练与游戏进程。

面向需要**开口**的人：法考主观题与面试训练、法学生辩论队、法制岗与公职律师、
企业法务、基层执法单位。
