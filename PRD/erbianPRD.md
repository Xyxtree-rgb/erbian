《耳辩》玩法重构需求文档 (PRD v1.0)
一、 核心目标
将现有的“四个冗余问答模式”重构为“沉浸式剧情探索 + 抬杠式辩论战斗”。核心体验类似《逆转裁判》或《弹丸论破》，玩家通过收集线索、选择证据、输入针对性发言来击溃对手的心理防线。

二、 UI 结构设计 (前端三视图)
抛弃原有的四个按钮，改为以下三个核心界面：

1. 主界面 (章节选择)
背景：保留第二页优雅的渐变背景（蓝粉光晕）。

中心视觉：放置书法Logo logo-earbian.png，下方保留“在你耳边 · 与你同辩”。

操作区：原“开始游戏”按钮改为“进入案件”，点击后进入剧情。

案件列表：类似书本目录，展示已解锁的章节（如：第一章 小卖部的过期水）。未解锁的显示“？？？”。

2. 剧情探索界面 (AVG视觉小说风)
背景：对应的场景插画（如：小卖部内部）。

人物立绘：左侧或右侧显示对话角色的表情立绘（老板娘、小明、玩家自己）。

对话框：底部留出三分之一的半透明区域，显示对话气泡。

交互元素：点击对话框继续剧情。场景中会有闪烁的“放大镜”图标，点击可收集证据（加入道具栏）。

底部菜单：道具栏（查看已收集的证据）、当前血量（心理防线）。

3. 辩论战斗界面 (核心玩法)
上半部分（对手）：对手立绘 + 破防血量条（血条会随着玩家有效发言而下降，对手会伴随震动、变红等特效）。

中段部分（对方发言）：对手会抛出一句狡辩台词，并带有倒计时（给玩家思考压力）。

下半部分（玩家操作区）：

操作面板：输入框（输入文字）、发送按钮、证据栏。

特殊技能（抬杠）：可设计特殊按钮，如“抛出证据”、“拍桌”、“情绪输出”。

反馈反馈：AI判定后，屏幕上出现“伤害 -15”特效，或者“无效发言”提示。

三、 故事文案大纲 (第一章示例)
*故事的核心在于：没有无厘头的抬杠，只有逻辑的碰撞。 *

章节标题：《第一章：小卖部的过期水》

剧情背景：中午，你的好朋友小明喝了学校小卖部刚买的水后上吐下泻。你去找老板娘理论，老板娘态度嚣张，拒不承认。你需要利用收集到的线索，在“对话辩论”中击败老板娘，让她赔偿。

探索阶段文案：

旁白：“正午的阳光很毒，小卖部的老板娘正坐在收银台后嗑瓜子。”

玩家：“老板娘，小明喝了你们的水拉肚子了！”

老板娘：“哎哟，小明是谁我不认识，他喝什么水管我什么事？”

证据收集：

证据1：小明手里的矿泉水瓶（点击查看：生产日期是上个月，保质期只有3天，已过期）。

证据2：小卖部货架背后的进货台账（点击查看：老板娘上周的进货记录里没有这款水）。

证据3：小明旁边同学小李的证言（点击查看：他亲眼看到小明刚买的水没喝完就肚子痛）。

辩论阶段（AI驱动）：

老板娘抛出第一个狡辩：“你有什么证据证明这水是在我这买的？我看就是他自己从外面带进来的！”

玩家可以发送：“请查看便利店监控！” 或者 点击“证据2：进货台账”。

AI System Prompt 要求：调用 DeepSeek，结合玩家发言与案件背景，如果符合逻辑，返回对手破防台词（如：“这……这进货单怎么被你翻到了！”），并扣除血量。

五、 AI System Prompt 改造要求 (后端核心)
你当前 app.py 里的 Prompt 需要升级为“游戏裁判和对手扮演者”。

新的 Prompt 示例：

“你是一个辩论游戏中的对手 NPC（小卖部老板娘）。当前场景是玩家指责你卖了过期水导致朋友生病，你正试图狡辩。
当前对手血量：{hp}
玩家发言：{user_input}
玩家持有证据：{evidence}
任务要求：

判断玩家发言是否有效（包含逻辑、证据、法条引用）。

如果有效：用‘气急败坏、破防’的语气回复一句话（如‘你……你胡说！这进货单绝对是你伪造的！’），并返回伤害值（15-30）。

如果无效：用‘嘲讽’的语气回复（如‘没有证据就别在这里血口喷人！’），返回伤害值为0。
返回格式必须为严格 JSON：{ "valid": true, "reply": "你……你胡说！", "damage": 20, "type": "事实" }”
