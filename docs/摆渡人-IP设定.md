# 摆渡人 · IP 设定

> 耳辩的主线角色。不是吉祥物，是一个人。
> 用于：社媒内容、动画分镜、开屏与转场、周边物料。

---

## 一句话

**他不替你说话。他只在岸上等你，等你把话说赢。**

## 为什么是他，不是四个辩风角色

青洏、桃弁、墨澜、择安是**四种辩风**——他们是"你怎么说"的四条路，是群像。
摆渡人是**"你为什么说"**——他是唯一有资格老去、有资格记住每一个过河的人的角色。

渡口的产品结构本身就是"你送走一个个人，自己也一年年老去"。这条情感线只能由一个人来扛。
四个角色负责让玩家反复来，摆渡人负责让玩家记得住。

## 世界观锚点

- **一条竖着的河**，从北往南，越走越宽，最后入海。
- 河上三座渡口，每座站着一个人，带着一件必须赢的事。
- 摆渡人不下船、不上岸。他只做一件事：**把人从这一岸，送到那一岸**。
- 他不打官司、不给建议、不说"你应该"。他只问一句：**"你要过河，你打算怎么说？"**
- 说赢了，船开。说输了，明天再来。

**关键设定**：他记不住所有事，但记得每一句"说赢了的"话。他的斗笠内侧，用炭笔写满了这些句子。这是他的履历，也是他的负担。

## 外形

| 项 | 设定 | 为什么 |
|---|---|---|
| 体型 | 瘦，肩窄，背微驼 | 撑了一辈子船。不是英雄，是干活的人 |
| 斗笠 | 深褐色，边缘磨白，内侧写满炭笔字 | 你只能从侧面看到那些字——他的记忆不给人看 |
| 脸 | 只看得到下半张。眼睛在斗笠阴影里，两道浅光 | 不抢戏。他是看你的人，不是被看的人 |
| 手 | 关节粗大，指缝有洗不掉的黑 | 握篙的手，比脸更有信息量 |
| 衣着 | 靛青短褐，下摆卷起，赤脚 | 靛青是两边共有的墨色，也是全片的色彩锚 |
| 道具 | 一根竹篙，篙头绑着一枚**印章** | 全片唯一的高饱和物件。判词落款就是它 |

**色彩纪律**：摆渡人身上只出现靛青（`#3d4a4f`）、磨白（`#f2efe7`）、炭黑。
唯一允许跳出来的是篙头那枚印章红（`#b4553f`）。
这和界面里的 `--gold / --gold-deep / --seal` 是同一套值——**角色和界面共用一套色，IP 才不会和产品割裂**。

## 黑白剪影可辨识度

做动画前先过这一关：把他涂成全黑，只留轮廓，还认得出吗？

能认出的三个特征（优先级从高到低）：
1. **斗笠 + 长篙的斜线**（一条斜线贯穿画面，是最好用的构图）
2. **微驼的背 + 短褐下摆**
3. **赤脚站在船头，船头翘起**

第 1 条最重要。任何一张图，只要这一条在，就是他。

---

## 性格：三句台词就能立住

他不劝人，不煽情，话说得短。

> "你要过河。"
> "你打算怎么说？"
> "……那你明天再来。"

**反面清单**（写错的信号）：
- ✗ 讲道理、给法律建议（那是知识库的事）
- ✗ 热情鼓励、喊口号（他不哄人）
- ✗ 说很长的话（他惜字）
- ✗ 自称"我"太多（他关心的是河，不是自己）

**气质参照**：不是师父，不是导师，是**手艺人**。像码头边修船的老人，你问他问题，他先干完手上的活。

---

## 成长弧：他一年年老去

这是他撑主线的方式，也是这个 IP 最有价值的地方——**他会随时间变化**。

| 阶段 | 玩家渡过的人数 | 他的变化 | 视觉 |
|---|---|---|---|
| 初 | 0–3 | 背还直，篙是新的 | 靛青偏亮，斗笠边缘整齐 |
| 中 | 4–10 | 开始咳，斗笠边缘磨白 | 靛青转深，多一道补丁 |
| 后 | 11–20 | 撑船时要换手，说话更少 | 白发出鬓角，篙身开裂 |
| 末 | 20+ | 坐在船头不再起身 | 斗笠全是字，人几乎融进雾里 |

**关键叙事点**：最后一个阶段，玩家会发现——**他也在等一个人来渡他**。
这条线留到第二季再揭，现在只需要在文案里埋一句"他从不提自己要过河"。

## 动画分镜（三个 5 秒短片，可直接做）

### 片 1 · 《过河》——产品首页循环

| 秒 | 画面 | 说明 |
|---|---|---|
| 0–1.5 | 全白，只有一条水平墨线，从中间慢慢洇开 | 河的诞生 |
| 1.5–3 | 墨线向下弯成河，一艘船的剪影从画面上方滑下 | 镜头跟着船走 |
| 3–4.5 | 船停。斗笠的斜线和长篙构成唯一的高光斜线 | 主角登场，不露正脸 |
| 4.5–5 | 印章红在篙头亮一下，画面转白 | 收 |

**循环点**：最后一帧的白 = 第一帧的白。可以无缝播一整天。

### 片 2 · 《说赢》——功能演示

| 秒 | 画面 | 说明 |
|---|---|---|
| 0–1 | 岸上两个人，一高一矮，隔着水 | 对峙 |
| 1–2.5 | 矮的人开口，画面浮出一句字，字有重量，把水面压出一道波纹 | "你说的话有分量" |
| 2.5–4 | 字沉不下去 → 弹回。人还在岸上 | 说空话，过不去 |
| 4–5 | 字沉下去了，船开。斗笠的斜线入画 | 说赢了 |

**这条片子的作用是让用户 5 秒内懂：这里要的是"说得对"，不是"说得响"。**

### 片 3 · 《斗笠》——品牌片

慢镜头。斗笠内侧的炭笔字，一句一句被光照亮，都是玩家说过的话（可做成 UGC 征集）。
最后停在一句空的横线上，笔搁在旁边。
字幕：**"下一句，是你的。"**

## 文案包

### 社媒简介（20 字内，可直接用）

- 他不替你说话，只等你把话说赢。
- 一条河，三座渡口，一个人。
- 说赢了船才开。

### 小红书 / 视频号 标题公式

> 【场景痛点】+ 【摆渡人的一句话】+ 【你的动作】

例：
- 「法考主观题说不出口？摆渡人不劝你，只问一句：你打算怎么说。」
- 「跟 HR 吵输了才想起法条。摆渡人说：那你明天再来。」
- 「我在河边站了三天，才把'试用期'三个字说对。」

### 五条可直接发的短内容

1. **「他不问你为什么来，只问你打算怎么说。」**
2. **「河上三座渡口。第一座，一个 19 岁的姑娘，工牌还没发下来。」**
3. **「摆渡人的斗笠里写满了话。都是别人说赢的。」**
4. **「说错了不丢人。丢人的是明天不敢再来。」**
5. **「所有法律 AI 都在帮你写完。没有人帮你辩赢。」**（← 品牌主张，最硬的一条）

### 开屏文案（现在这版可以直接替换）

```
在你耳边 · 与你同辩
```
建议改为主角口吻，更有钩子：
```
你要过河。
你打算怎么说？
```

## 与现有资产的关系

- **VI 的四个钥匙孔角色**（青洏/桃弁/墨澜/择安）：保留，作为"辩风"的选择项，不当主线。
- **钥匙孔造型**（`erbian.svg`）：已经用在穿越转场的 Logo 绽开上。摆渡人的印章红与它是同一色系。
- **签名位**：`在你耳边，与尔同辩` 保留为产品 slogan，摆渡人台词是**独立一层**，不抢 slogan。
